# CINIS – Die letzte Flamme

Rom ist gefallen. Asche bedeckt die sieben Hügel. Im Zentrum der Ruinen brennt die **Ewige Flamme** – das letzte Licht der Stadt. Sammle Rohstoffe, baue eine Siedlung auf und verteidige die Flamme 30 Nächte lang gegen die Aschgänger.

## Starten
```
npm start        # oder: python3 -m http.server 8080
```
Dann http://localhost:8080 öffnen.

## Steuerung
| Aktion | Taste |
|---|---|
| Bewegen | WASD / Pfeiltasten |
| Zoom | Mausrad |
| FPS-Anzeige | F3 |
